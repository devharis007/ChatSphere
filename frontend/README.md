# ChatSphere — Frontend

React 19 + TypeScript client for ChatSphere, built with Vite and `@microsoft/signalr`.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # type-check + production build
npm run lint
```

The API/hub URL defaults to `http://localhost:5082`; override it with a `VITE_API_BASE_URL`
environment variable. See the [main README](../README.md) for the full project overview.
